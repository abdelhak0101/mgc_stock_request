# MGC Stock Request

Custom Odoo 14 module for managing stock requests and warehouse delivery operations.

## Features

- Stock request management
- User and manager approval workflow
- Warehouse/location access control
- Stock picking integration
- Tier validation
- Product access restrictions
- Custom delivery workflow
- Stock request report
- Email notifications
- French translation

## Technologies

- Odoo 14
- Python
- XML
- PostgreSQL
- Odoo ORM

## Module Structure

- `models/` - Business logic and Odoo models
- `views/` - User interface and form/tree views
- `security/` - Access rights and security rules
- `data/` - Sequences and email templates
- `reports/` - Stock request reports
- `i18n/` - French translation

## Installation

1. Copy the `mgc_stock_request` module into your Odoo addons directory.
2. Restart the Odoo server.
3. Update the Apps list.
4. Search for **MGC Stock Request**.
5. Install the module.

## Odoo Version

Odoo 14
